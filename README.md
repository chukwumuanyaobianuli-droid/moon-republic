# Moon Republic - About Website

A professional, modern website for Moon Republic, a community for young Nigerians learning money-making skills.

## Features

- **Modern Design**: Professional, responsive layout built with Next.js and Tailwind CSS
- **Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- **Fast Performance**: Optimized for speed with Next.js
- **SEO Friendly**: Built-in SEO best practices
- **Scalable**: Easy to add more features and pages

## Sections

1. **Hero** - Eye-catching landing section with key stats
2. **About** - Community mission and vision
3. **Skills** - Six key skill areas (Programming, Forex, AI, Ghost Writing, Visual Assistance, Financial Literacy)
4. **Community** - Benefits and features of joining
5. **CTA** - Call-to-action for new members
6. **Footer** - Contact info and links

## Getting Started

### Prerequisites
- Node.js 16+ installed
- npm or yarn

### Installation

1. Navigate to the project folder
```bash
cd "Moon Republic"
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```

## Customization

### Update Content
- Edit component files in `/components` folder
- Update colors in `tailwind.config.js`
- Modify metadata in `app/layout.tsx`

### Key Files
- `app/page.tsx` - Main landing page
- `app/layout.tsx` - Root layout
- `components/` - Reusable React components
- `app/globals.css` - Global styles

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **React 18** - UI library
